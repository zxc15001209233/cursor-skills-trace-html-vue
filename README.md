# Cursor Skills · 截图 / Axure → Vue-ready HTML → Vue3

追溯 / 中后台原型落地流水线（Cursor Agent Skills）。

## Skills

| Skill | 作用 |
|-------|------|
| [`screenshot-to-vue-ready-html`](./screenshot-to-vue-ready-html/) | 截图 → Vue-ready HTML |
| [`axure-html-restore`](./axure-html-restore/) | Axure 导出 → Vue-ready HTML（echarts 1:1） |
| [`vue-ready-html-to-vue3`](./vue-ready-html-to-vue3/) | Vue-ready HTML → 独立 Vue3 工程 |

串联说明见 [PIPELINE.md](./PIPELINE.md)。

## 安装到 Cursor

复制到个人 skills 目录：

```bash
cp -R screenshot-to-vue-ready-html axure-html-restore vue-ready-html-to-vue3 ~/.cursor/skills/
```

或在对话中 `@` 引用本仓库中的 `SKILL.md`。
